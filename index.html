📋 Supabase Setup Guide
Step 1 — Create Supabase project
Go to supabase.com → New project → Choose a name (e.g. "alanees-meetings") → Set a strong database password → Create project.
Step 2 — Create the table
In your Supabase project go to SQL Editor and run this SQL:
CREATE TABLE meeting_minutes ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, created_at timestamptz DEFAULT now(), title text NOT NULL, meeting_date text, start_time text, room text, organizer text, duration text, summary jsonb, key_points jsonb, decisions jsonb, action_items jsonb, attendees jsonb, raw_transcript text ); -- Allow public read/write (for demo) ALTER TABLE meeting_minutes ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow all" ON meeting_minutes FOR ALL USING (true) WITH CHECK (true);
Step 3 — Get your API keys
Go to Project Settings → API. Copy:
• Project URL (e.g. https://xxxx.supabase.co)
• anon / public key
